

# OntologyDesignTemplate
Crear ontologías es divertido, pero ¿cómo asegurarse de que personas que no son expertas en RDF entiendan sus ideas?

Esta plantilla ayuda a los desarrolladores de ontologías a diseñar ontologías visualmente atractivas que puedan presentarse a otros. 
Simultáneamente, puede utilizarse como una bitácora para versiones anteriores, y como un espacio para almacenar ideas o los resultados de una sesión de lluvia de ideas. 
Está pensada para ser un cuaderno de bocetos digital que puede utilizarse durante todo el ciclo de vida de la ontología. 

El documento contiene diversos elementos de diseño que pueden emplearse para crear ontologías e instanciaciones de ontologías.
